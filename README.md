# Job-RAG

AI 招聘岗位语义检索知识库（初始化阶段）。

## 数据来源与范围

来源：BOSS直聘_AI岗位数据库_清洗规整版_20261024 中的「历史_岗位去重总表」。本次快照共 593 条职位记录，325 条有非空职位描述。仅用于学习与分析；岗位状态和薪资可能随时间变化，不保证当前招聘有效。

## 文件组织

- `data/jobs/part-*.jsonl`：岗位标准化元数据，按职位 ID 定位，保留未补齐详情的职位。
- `data/documents/part-*.jsonl`：首批语义文档，供后续 Embedding；暂时没有向量或模型绑定。

**隐私边界**：公开仓库不包含招聘者姓名、活跃信息、工商登记原文和长篇公司介绍；如有需要，原始 Excel 应存放于非公开位置。本项目仅保留分析所需的岗位字段。不要把 API Key、个人简历等私有材料提交到仓库。

## 数据约定

- 唯一键：`job_id`，取自「职位ID」，不使用序号作为业务主键。
- 文本层：一岗一文档，当前不进行切块和摘要，不推断新标签。
- 无详情岗位保留在 `jobs` 中，但不生成空的向量文档。
- 后续更新：优先以 job_id 做 upsert，文本变化后再重新生成向量；本次为静态快照。

## 后续方向

先验证文本质量与检索相关性，再选择 Embedding 模型、向量存储和混合检索；筛选条件（城市、薪资、经验等）应使用结构化过滤，而非只依赖向量相似度。
