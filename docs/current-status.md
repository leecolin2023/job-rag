## 运行链路

```text
远端 OpenCode / 其他 harness
  → HTTPS :443 /mcp（既有宿主机 nginx）
  → 127.0.0.1:8443（Docker 网关，令牌校验和限流）
  → MCP → API → PostgreSQL + pgvector

本机网页/API：127.0.0.1:8008
本机 MCP：127.0.0.1:8009/mcp
```

公网 endpoint 不是演示用匿名服务；使用者需通过安全渠道获得令牌。调用方自己的模型账户与额度由调用方维护，服务器不共享 OpenCode Go 凭据。

## 验证结果

| 验证 | 结果与范围 |
|---|---|
| `pytest -q` | 36 项通过；覆盖导入、更新、下架、检索、降级、鉴权等 |
| `scripts/check_postgres.py` | 在隔离数据库中验证真实 pgvector 写入/距离查询、版本替换和关闭过滤；向量为测试替身 |
| `scripts/check_mcp.py` | 握手、工具目录、统计、候选召回与详情调用通过；支持本机及带令牌的公网入口 |
| DeepSeek harness | 已使用 `opencode-go/deepseek-v4.1-flash` 执行统计→改写召回→详情复核→回答 |
| 公网安全检查 | 缺少/错误/大小写变更的令牌返回401；正确令牌可调用；系统默认信任验证 TLS 通过 |
| 现有站点 | 增加精确 `/mcp` 路由后原网站仍返回200；未改动其他路由或现有续期机制 |

脚本结果是功能检查，不等同于检索质量基准、渗透测试或并发压力测试。GitHub CI 运行 Python 测试，不自动部署公网服务，也不依赖线上密钥。

## 尚未完成

1. **真实向量生成**：当前线上未配置 Embedding。DeepSeek 是查询理解与重排模型，不是向量模型；pgvector 集成已验证不等于已启用线上向量召回。
2. **岗位有效性自动维护**：无网站爬虫、周期在线核验和自动截止日期识别；需要合法来源的数据刷新或人工依据。
3. **质量与评测**：暂无经过人工标注的检索相关性基准；重复/多岗位内容识别和字段冲突治理仍需完善。
4. **生产运维**：当前为单写入者索引任务，没有数据库迁移工具、分布式队列、自动备份和证书到期告警。
5. **权限与审计**：公网使用共享只读令牌，未实现多租户隔离、每用户配额或完整请求/响应审计。
6. **部署可迁移性**：宿主机 nginx 安装脚本、路径、IP 和现有证书属于当前服务器；新机器应按实际情况配置，不可盲目执行。
