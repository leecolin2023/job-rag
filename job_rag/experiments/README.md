# 离线检索与重排实验

本目录独立于在线查询路径，用于可复现评测，不为正常岗位搜索请求执行实验。

| 文件 | 职责 |
|---|---|
| `cli.py` | `job-rag-experiment` 命令入口 |
| `runner.py` | 冻结数据与问题、不同表示的召回、固定候选重排、候选审阅池、补标后重算及报告 |
| `bailian.py` | 实验模型适配、缓存、脱敏日志与费用保护 |
| `metrics.py` | 按标注口径计算排名指标与 bootstrap 对比 |

第一轮对照旧固定1100、紧凑固定1100、章节1100、章节加条件1100、章节加条件600；同一岗位取最高分块向量相似度，再返回岗位级Top-50。线上先融合检索通道的Chunk排名再聚合岗位，二者不能直接等同。

第二轮比较固定候选上的不重排、BM25、章节规则、Qwen默认及招聘指令重排。完整付费第二轮尚未执行；探针成功不代表已有全量收益结论。

现有30条查询主要只有一个种子正例，不能把其他未标注岗位当负例，或用种子排名断言总体真实召回。补充判断后可 `rescore`，不必重新调用 Embedding。

目录重组后实现指纹覆盖新的分块、预处理、检索及共享过滤/序列化文件路径。历史冻结数据与结果不改写，不绕过指纹校验；复核历史运行应使用对应版本代码。运行期数据保存在 `runtime/`，不与代码一起发布。

使用说明见[实验入口](../../experiments/README.md)、[实验协议](../../docs/embedding-experiments.md)和[已有结果](../../docs/recall-pilot-2026-10-25.md)。本次整理不调用付费模型，不重跑历史实验。
