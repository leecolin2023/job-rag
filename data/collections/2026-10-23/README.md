# 2026-10-23 BOSS直聘搜索岗位采集快照

本目录存放 BOSS直聘在 2026-10-23 采集的 Agent 和 RAG 搜索结果，来自工作簿 `BOSS直聘_AI岗位数据库_清洗规整版_20261024.xlsx`。

| 文件 | 关键词 | 原始结果数 | 当前去重后岗位数 | 不同职位 ID 数 | 字段数 |
| --- | --- | ---: | ---: | ---: | ---: |
| `agent.csv` | Agent | 299 | 288 | 288 | 11 |
| `rag.csv` | RAG | 300 | 300 | 300 | 11 |

## 字段

`搜索关键词`、`职位名称`、`公司（卡片）`、`工作区域`、`薪资（页面展示）`、`经验或实习要求`、`学历要求`、`职位详情链接`、`岗位职责与任职要求原文`、`采集日期`、`职位ID`。

## 去重说明

2026-10-30 对 `agent.csv` 按 `职位ID` 去重：11 个职位 ID 各重复一次，删除 11 条重复记录。9 组重复记录的全部保留字段完全相同；另外 2 组中，一组 JD 仅排版有差异，另一组是有效 JD 与占位值 `4` 的冲突。保留 JD 有效且更完整的记录，同等完整时保留首次出现记录。其他字段保持原值，`rag.csv` 没有同批重复职位 ID，未修改。

## 使用边界

- 这两个 CSV 按**搜索关键词**保留独立集合。Agent/RAG 两份之间仍有 46 个重合职位 ID；做联合统计需以 `source:job_id` 去重。
- 搜索命中关键词不是岗位技能标签，需从岗位职责与任职要求原文核实实际技术要求。
- Agent 当前有 20 条、RAG 有 150 条的 JD 为占位符 `4`，不能直接用于技术要求统计或向量索引。主表 `data/jobs.csv` 对其中多数岗位已有有效正文，不应被占位符覆盖。
- 当前 CSV 保留中文列名，不是现有 `job-rag import` 可直接读取的标准结构；当前导入器还要求英文列名、`status` 和 `collected_at` 等字段。
- 本次仅修改采集快照及其说明，不修改 `data/jobs.csv` 或运行时索引。完整交叉对比参见 [COMPARISON_WITH_JOBS.md](COMPARISON_WITH_JOBS.md)。
