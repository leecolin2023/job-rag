# 公司信息补充表

`company_info.csv` 是原 `data/collections/公司信息.csv` 的**原样迁移**，包含跨批次抓取的公司相关材料，不是按日期的单次岗位快照。数据搬迁不重新生成、清洗、去重或重写该 CSV。

- 岗位原始快照统一放 `../collections/YYYY-MM-DD/*.csv`，只通过 `../data_merge/merge_jobs.py` 汇总进入 `../jobs.csv`。
- 本表暂按采集来源的 `职位ID` 与岗位 `job_id` 关联；同一职位可能有多行信息，分析时先去重。**这不是跨平台统一公司 ID，也不能仅凭同名认定为同一法人。**
- 上层 `../../apply-flow/` 可读取公司业务描述，生成“公司在做什么、岗位具体做什么”的人工分析结论，写入 `jobs.csv.analysis`。
- 岗位合并器不会因本表变化重写人工分析、招聘状态或原始 JD。公司信息需要维护独立质量规则时，另行设计，不混进岗位采集快照。
